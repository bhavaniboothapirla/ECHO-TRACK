
# 🌱 EcoTrack – Daily Sustainability Logger

**Track Your Actions. Measure Your Impact. Build a Greener Future.**

EcoTrack is a web-based sustainability tracking application designed to encourage people to adopt eco-friendly habits in their daily lives. It allows users to record sustainable activities and understand their positive environmental impact through estimated CO₂ emissions reduced, water saved, and waste diverted.

## 📌 Project Overview

Environmental protection starts with small everyday actions. Activities such as cycling instead of driving, avoiding single-use plastics, saving water, and recycling can make a meaningful difference.

EcoTrack helps users monitor these activities, maintain daily streaks, and visualize their environmental contributions through an interactive dashboard.

## ✨ Key Features

- 🌍 **Daily Activity Logging:** Record everyday eco-friendly activities.
- 🌱 **CO₂ Savings Tracking:** Estimate carbon emissions avoided.
- 💧 **Water Conservation:** Monitor estimated water savings.
- ♻️ **Waste Reduction:** Track waste diverted from landfills.
- 🔥 **Daily Streaks:** Maintain consistency with sustainable habits.
- 📊 **Interactive Dashboard:** Visualize environmental impact and weekly progress.
- 📈 **Progress Analytics:** Monitor cumulative sustainability achievements.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd EcoTrack
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open in your browser**

Visit the local URL displayed in your terminal.
